# Code of Conduct - Zasady postępowania

1. Cel

Zasady te zostały stworzone z myślą o pozytywnej atmoswerze, aby każdy członek zespołu czół się tu mile widziany i szanowany.

2. Zasady współpracy

Proszę o komunikowanie się do siebie z szacunkiem, pomoc innym, gdy napotkają błąd oraz o transparętność.

3. Niedopuszczalne zachowania

Niedopuszczalne są wyzwiska, trollowanie, nękanie, znęcanie, stalkowanie, utrodnianie współpracy, dyskryminacja, oraz obraźliwe zachowanie wobec współpracowników.

4. Code Review
- Oceniaj kod, a nie autora;
- Formułuj uwagi w sposób konkreny;
- Uzasadniaj proponowane zmiany

5. Zgłaszanie naruszeń

W przypadku zgłaszania naruszeń należy skontaktować się bezpośrednio z administratorem projektu. Zgłoszenia te są poufne, co znaczy, że osoba zgłoszona nie dowie się kto ją zgłosił.

6. Konsekwencje naruszeń
Dla osoby naruszającej zasady zachowania są 3 stopnie konsekwencji w zależności od szkodliwości i częstotliwości zachowań:
- upomnienie;
- czasowe zawieszenie uprawnien;
- trwałe wykluczenie z projektu.

**Współpraca, wzajemny szacunek i odpowiedzialność za własną pracę są podstawą rozwoju tego projektu!**
